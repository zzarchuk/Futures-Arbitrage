Arbitrage Spread Monitoring API

Backend-focused system for real-time cryptocurrency spread detection across multiple exchanges.

📌 Overview

This project is a backend-heavy system built with FastAPI, designed to identify arbitrage opportunities across crypto derivatives markets.

It aggregates data from multiple exchanges (Binance, Bybit, OKX, KuCoin, MEXC, Bitget, Gate, HTX, BingX), filters tradable instruments, and streams real-time spreads via WebSocket.

⚙️ Architecture

  • Data Discovery Layer — collects available futures pairs across exchanges
  • Filtering Engine — selects assets traded on ≥2 exchanges with spread potential
  • Streaming Layer — connects to exchange WebSockets (orderbooks, funding)
  • Computation Engine — calculates spread & funding-adjusted spread
  • Delivery Layer — REST API + WebSocket streaming
  • Storage Layer — SQLite (SQLAlchemy)

📡 REST API

GET /api/v1/market/spreads?symbol=BTC&min_spread=0.5

Returns real-time spreads in JSON format

GET /api/v1/market/spreads/stream

Simple dashboard with live WebSocket feed

GET /api/v1/analytics/spreads/chart

Spread chart + historical data

GET /api/v1/market/spreads/top

Top spreads over selected period

GET /api/v1/market/statistics

Aggregated statistics

GET /api/v1/config/blacklist

Blacklisted symbols

GET /api/v1/filters

Active filtering configurations

GET /api/v1/system/parser/status

Parser state (running / stopped)

🛠 Management

POST /api/v1/filters

Create new filter

POST /api/v1/alerts

Create alert for symbol or spread threshold

POST /api/v1/system/parser/start

Start parser

POST /api/v1/system/parser/stop

Stop parser
